A tiny Node program that writes one alien tourist's one-line review of planet Earth (at most 200 characters) to the make.fun harness output file. After two days of field observation, our reviewer noticed who really runs the planet: the humans trail behind a smaller animal on a rope, bag its droppings, and still call themselves its owner. The verdict is in the line itself — deterministic, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
